# Persona

To give more detailed information about the character persona behind a user, vTual provides the [Persona menu](https://www.vtual.net/apps/account-manager/persona).

![vTual persona settings](/assets/docs/vtual/App_Persona.webp)

You can select multiple options regarding your own character persona, which makes it easier for potential viewers to find what they are interested in. This feature improves discoverability and helps connect your content with the right audience based on their persona preferences.

:::tip
If a character persona is not listed, contact us so we can add it to our database.
:::
