# Main Language

To give more detailed information about the main language a user brings, vTual provides the [Language menu](https://www.vtual.net/apps/account-manager/language).

![vTual language settings](/assets/docs/vtual/App_Language.webp)

You can select multiple options regarding the main language of your channel, which makes it easier for potential viewers to find what they are interested in. This feature improves discoverability and helps connect your content with the right audience based on their language preferences.

:::tip
If a language is not listed, contact us so we can add it to our database.
:::
