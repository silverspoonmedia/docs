# Main Content

To give more detailed information about the main content a user brings, vTual provides the [Content menu](https://www.vtual.net/apps/account-manager/content).

![vTual main content settings](/assets/docs/vtual/App_Content.webp)

You can select multiple options regarding the main content you create on your channel, which makes it easier for potential viewers to find what they are interested in. This feature improves discoverability and helps connect your content with the right audience based on their content preferences.

:::tip
If a content type is not listed, reach out to us so we can add it to our database. Your feedback helps us expand our offerings and serve the community better.
:::
