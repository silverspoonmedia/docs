# Handler

Each user has a unique handler that can be used to access their profile. You can customize this handler to suit your preferences through the [Handler menu](https://www.vtual.net/apps/account-manager/handler).

![vTual handler settings](/assets/docs/vtual/App_Handler.webp)

Every handler starts with **eight random letters**, followed by your preferred handle, for example `abcdefgh.my-handler`. This format guarantees a unique identifier for every user while still allowing personal expression in the latter part.

:::note
Full personalization without the eight random characters may become a paid feature in the future, if proven necessary.
:::

For now, the handler only supports the alphabet. Other writing systems, such as Arabic, Kanji, and Hangul, are not yet supported.
