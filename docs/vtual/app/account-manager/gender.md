# Gender Representation

To give more detailed information about the gender a user represents, vTual provides the [Gender menu](https://www.vtual.net/apps/account-manager/gender).

![vTual gender settings](/assets/docs/vtual/App_Gender.webp)

You can select multiple options regarding your own gender representation, which makes it easier for potential viewers to find what they are interested in. This feature improves discoverability and helps connect your content with the right audience based on their gender preferences.

:::tip
If a gender representation is not listed, contact us so we can add it to our database. Your input helps ensure inclusivity and diversity.
:::
