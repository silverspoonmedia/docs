# Oshi

In vTual, a user you follow is categorized as an **Oshi**.

![vTual Oshi list](/assets/docs/vtual/Simp_Oshi.webp)

To help you manage your list of Oshis, you can access the **Oshi** menu. There you can search, view their profiles, and unfollow them if you choose.
