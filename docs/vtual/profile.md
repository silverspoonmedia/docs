# Profile

Every user has a profile page that can be accessed publicly through their unique handler.

![vTual profile page](/assets/docs/vtual/Profile.webp)

The profile contains basic information, including personal details and the content the user has created. It serves as a showcase of their contributions and lets others learn more about them.

To make it easier to reach content from a specific user, a search feature is available. It applies to all content types, including live, scheduled, archived, and VOD (Video on Demand).

That means users can quickly find and explore the content they are interested in, which improves the overall experience on the platform.
