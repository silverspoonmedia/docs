# About Archivd

Archivd is Silverspoon's file storage product: a lightweight drive for keeping, organizing, and sharing your files, plus paid team workspaces for working on the same files together.

It is deliberately simple. If you have used a cloud drive before, everything here should feel familiar: folders, drag and drop, a trash bin, and shareable links. No labyrinth, no ritual sacrifice, no mysterious button that only works on Tuesdays.

## What you get

- **A personal drive.** Nested folders, upload, rename, move, search, and a trash bin you can restore from.
- **Link sharing.** Mark a file or folder as shareable and send the link to anyone. No account needed on the other side.
- **Team workspaces.** Paid owners can create workspaces, invite people by email, and assign roles so everyone sees only what they should.
- **A predictable storage quota.** A free allowance for everyone, with paid plans and add-ons on top when you need more room.

## How it is organized

| Concept | Meaning |
|---------|---------|
| Personal drive | Your own space. Everything here belongs to you alone. |
| Folder | A container you can nest as deep as you like. |
| File | An uploaded object. Files live inside a folder or at the root of a drive. |
| Workspace | A shared space owned by a paid account, with members and roles. |
| Trash | Deleted items wait here before they are removed for good. |
| Blocklist | A staff-maintained list of blocked file contents, used for takedown requests. |

## Two spaces, one interface

When you open Archivd you start in your **personal drive**, also called My Files. If you own or have joined any workspaces, a switcher lets you jump between your personal drive and each workspace. The personal tree never mixes with a workspace tree, so it is always clear whose files you are looking at.
